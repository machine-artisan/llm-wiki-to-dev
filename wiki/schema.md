# LLM-Wiki Schema

이 스키마는 에이전트가 위키를 읽고 쓸 때 따라야 할 규칙을 정의합니다.

## 페이지 목록

| 파일 | 역할 | 업데이트 트리거 |
|------|------|----------------|
| `profile.md` | 이름, 소속, 직함 | 소속/역할 변경 시 |
| `interests.md` | 기술 관심사 목록 | 새 관심사 추가·제거 시 |
| `goals.md` | 현재 목표 (3–5개) | 목표 변경 시 |

## 페이지 형식 규칙

- 각 페이지 상단에 `updated: YYYY-MM-DD` 메타데이터 포함
- 항목은 bullet list (`-`) 사용
- 항목당 한 문장, 50자 이내
- 모순된 내용은 `[CONFLICT]` 태그로 표시
- 오래된 항목(6개월 이상)은 `[STALE]` 태그로 표시

## Ingest 규칙

1. 소스 파일을 읽고 위키 관련 페이지를 업데이트
2. 기존 내용과 중복되면 병합 (추가 금지)
3. 모순이 발생하면 최신 소스 기준으로 덮어쓰되 `[CONFLICT]` 기록
4. 소스 처리 후 `sources/processed/` 로 이동

## Build 규칙

1. `profile.md`, `interests.md`, `goals.md` 를 읽는다
2. 내용을 바탕으로 `index.html` 을 생성한다
3. 디자인 일관성 유지 (다크 테마, 모바일 대응)
4. `[CONFLICT]` / `[STALE]` 항목은 카드에 포함하지 않는다
