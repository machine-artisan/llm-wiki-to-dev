# LLM-Wiki Schema

이 파일은 당신(LLM)이 이 위키를 읽고 작업할 때 반드시 따라야 할 규칙입니다.
규칙을 추측하거나 응용하지 마세요. 여기 적힌 내용을 그대로 따르세요.

---

## 1. 위키 파일 목록과 역할

이 위키는 아래 3개 파일로 구성됩니다. 각 파일의 역할은 다음과 같습니다:

| 파일 | 담고 있는 정보 | 예시 |
|------|--------------|------|
| `profile.md` | 이 사람이 누구인지 (이름, 소속, 연락처) | 이름: 김철수 |
| `interests.md` | 이 사람이 관심 있는 것들 | AI 도구 활용 |
| `goals.md` | 이 사람이 앞으로 하고 싶은 것들 | 첫 웹페이지 배포 완료 |

---

## 2. 파일 형식 규칙

모든 위키 파일은 아래 형식을 정확히 따릅니다.

### 올바른 형식 (반드시 이 형식 사용):
```
---
updated: 2026-04-16
---

# 제목

- 항목1
- 항목2
- 항목3
```

### 규칙:
- 첫 줄은 반드시 `---` 로 시작
- `updated:` 다음에는 오늘 날짜를 `YYYY-MM-DD` 형식으로 작성
- `---` 로 닫은 후 빈 줄, 그 다음 `# 제목`
- 내용은 `-` 로 시작하는 목록 형식
- 각 항목은 한 줄, 40자 이내로 작성

### 잘못된 형식 (사용 금지):
```
# 제목          ← updated 메타데이터 없음
* 항목          ← * 대신 - 사용해야 함
항목 내용       ← - 없이 작성 금지
```

## 3. Ingest 작업 규칙 (소스 파일 → 위키 업데이트)

`ingest.py` 가 소스 파일을 주면, 아래 순서대로 처리하세요.

**순서:**
1. 소스 파일 전체를 읽는다
2. 아래 표를 참고해서 어느 위키 파일을 업데이트할지 결정한다
3. 기존 위키 내용과 비교한다
4. 새로운 정보만 추가한다 (이미 있는 내용은 다시 쓰지 않는다)
5. 모순이 있으면 `[CONFLICT]` 태그를 붙인다

**어떤 정보가 어느 파일로 가는가:**
| 소스에서 발견한 정보 | 업데이트할 파일 |
|-------------------|--------------|
| 이름, 소속, 직함, 이메일, GitHub 주소 | `profile.md` |
| 관심 분야, 좋아하는 것, 배우고 싶은 것 | `interests.md` |
| 목표, 앞으로 하고 싶은 것, 계획 | `goals.md` |

**응답 형식 (반드시 이 형식으로만 응답):**
```
<page name="파일명">
---
updated: YYYY-MM-DD
---

# 제목

- 항목1
- 항목2
</page>
```

변경이 없는 파일은 응답에 포함하지 않습니다.

## 4. Build 작업 규칙 (위키 → index.html 생성)

`build_card.py` 가 위키 3개 파일을 주면, 아래 규칙으로 HTML 을 생성하세요.

**반드시 지켜야 할 규칙:**
1. `<!DOCTYPE html>` 로 시작하는 완전한 HTML 파일을 출력한다
2. 외부 CSS, 외부 JS, 외부 폰트를 사용하지 않는다 (인터넷 연결 없이도 열려야 함)
3. 모바일에서도 깨지지 않도록 `<meta name="viewport" content="width=device-width, initial-scale=1.0">` 를 반드시 포함한다
4. `[CONFLICT]` 또는 `[STALE]` 태그가 붙은 항목은 HTML 에 포함하지 않는다

**HTML 에 포함해야 하는 내용:**
- `profile.md` 의 이름 → 페이지 제목(`<title>`)과 카드 상단에 표시
- `profile.md` 의 소속, 직함 → 이름 아래에 표시
- `goals.md` 의 목록 → "Goals" 섹션에 표시
- `profile.md` 의 GitHub, 이메일 → 하단 링크 버튼으로 표시

**디자인 규칙:**
- 배경색: `#0f1117` (어두운 남색)
- 카드 배경색: `#1a1d27`
- 강조색: `#6c63ff` (보라)
- 보조 강조색: `#48cfad` (민트)
- 글자색: `#e8eaf6` (밝은 회색)
- 카드는 화면 중앙에 배치, 최대 너비 420px
- 이름 첫 글자를 원형 아바타로 표시 (그라디언트: 보라 → 민트)
